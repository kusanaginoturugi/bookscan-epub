ePub化の方針と調査メモ

2026-11-13 時点の調査結果。まだ何も実装していない。

位置づけ

今の成果物は検索可能PDFで、その方針は変えない。ePubは、検索可能PDFを作る流れで得た行ごとのテキスト（work/searchable/作業名/lines.tsv の final）から作る、追加の成果物とする。data/epub-candidates.tsv は、検索可能PDFへ方針を変える前の旧EPUB方針での選別結果で、この計画とは別物。

抜き取り検査（README の「現時点の成果」）では、『星を継ぐもの』の完成版は200行・7501字で誤り0、人の判定なしの機械処理だけでも誤り1字だった。本文の文字は、ePubの元にできる水準にある。

方針：青空文庫形式をベースにする

ePubのXHTMLとCSSは自前で設計しない。本文を青空文庫の書式（注記つきテキスト）で書き出し、既存の変換ツール AozoraEpub3 でePub 3にする。

理由:

  • 仕組みを増やさない（ユーザーの方針）。縦書きの組版やePubの構造は、ツールと、その元になっている電書協ガイドに任せる。
  • 青空文庫の注記と全角・半角の使い分けで、縦書きの中の英数字の組み方（縦中横、正立、横倒し）を表し分けられる（下の表）。
  • ルビ（｜漢字《かんじ》）、傍点、字下げ、見出しも同じ書式に載る。今は捨てているルビの行を拾う段になっても、形式を変えずに済む。

検索可能PDFの文字層は、英数・記号を半角のままにする（「UNSA」で検索して全角の「ＵＮＳＡ」に当たらないビューアが多い）。全角への置き換えと縦中横の注記は、青空文庫形式で書き出すときだけ行う。

青空文庫の注記（調査結果）

公式の注記一覧（その他の注記）より:

  • 縦中横：縦組みの中で横並びに組まれた文字は ○○［＃「○○」は縦中横］ と書く。例は 米機Ｂ29［＃「29」は縦中横］の編隊は、。外字注記を含むときは ［＃縦中横］…［＃縦中横終わり］ で囲む。
  • 横組み：行中の文字は ○○［＃「○○」は横組み］。ただし、横組みされた文字が半角（1バイト）の英数字・記号で入力すべきものなら、注記は要らない。縦組み中のブロックは ［＃ここから横組み］〜［＃ここで横組み終わり］。
  • 欧文の引用符：1バイトの欧文を囲む引用符は、全角の “ ” ‘ ’ で入力する。

ここから、原本の組み方と入力の対応は次のように読める（注記一覧の書き方からの読み取りで、明文の規則としては未確認）。

原本の組み方 例 青空文庫での入力
縦中横（1マスに横並び） 2桁の数字、「!?」 半角で入力し、縦中横の注記を付ける
正立（1字1マス） 1桁の数字、略語の英字、「？」「！」 全角で入力する（Ｂ、？）
横倒し（字が寝ている） 英単語、英文 半角で入力する（注記なし）

AozoraEpub3（調査結果）

  • 青空文庫の書式のテキストをePub 3に変換するツール。今は、電書協 EPUB 3 制作ガイドに合わせた改良版が GitHub（kyukyunyorituryo/AozoraEpub3）で続いている。Java製。
  • 自動縦中横：半角数字2文字と、2〜3文字の「!」「?」を、注記がなくても縦中横にする。1桁・3桁の数字や1文字の「!?」を縦中横にするかは設定で変えられる。前後に全角文字がない場合（間の半角空白は無視）と、横組み注記の中では効かない。
  • 半角英数字の全角化についての記載は見当たらない。「正立」は独自対応の注記の一覧に名前があるだけで、動作の説明はない。
  • ライセンスは GPL v3。作ったePubの権利は入力データと同じ扱い。外部ツールとして呼ぶだけなので、このリポジトリのコードには影響しない。

まだ実際に動かしていないので、上の挙動は README の記載によるもの。

このプロジェクトでの進め方（案）

  1. lines.tsv の final から、青空文庫の書式のテキストを書き出す。2桁の数字と「!?」は AozoraEpub3 の自動縦中横に任せる。
  2. 原本の画像で英数字の組み方を判定し、自動の規則から外れるものにだけ注記を付け、全角・半角を切り替える。判定は、英数字のかたまりが行の中で占める長さで行う。縦中横は2字で1マス、正立は1字1マス、横倒しは1字が半マス前後で字ごとに幅が違う。行の画像を字の切れ目で区切って測る（パ／バの語の切り出しと同じ考え方）。迷うものだけ、今のレビュー画面と同じ方式で人に回す。
  3. 縦中横と判定した位置は、切り出して横向きに読み直す。NDLは1マスに詰まった「12」を読めていない。
  4. AozoraEpub3 でePubにする。

量の目安：『星を継ぐもの』の縦書きの行には、半角の英数・記号のかたまりが861個ある。内訳は ? 334、英字185、英数の混在58、数字29、括弧46、! 25など。? と ! はほぼ機械的に全角にでき、判定が要るのは英字と数字の200個程度。

まだ調べていないこと

  • 段落の組み立て。文字層は行単位なので、行をつないで段落に戻す（字下げで段落の始まりを見分ける）必要がある。柱とノンブルを本文から外し、章見出しを ［＃大見出し］ などで表すことも要る。
  • ルビ。今は本文の行だけを使い、ルビの行は捨てている。
  • 電書協ガイドのCSSで縦中横・正立・横倒しに使うクラス名。AozoraEpub3 を使うならツール任せにできる。
  • AozoraEpub3 の実際の出力と、電子書籍リーダーでの見え方。
