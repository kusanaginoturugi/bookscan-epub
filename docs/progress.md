## 方針

1. NDLOCRとPaddleOCRの領域・行を座標で対応付け、文字単位の差分を検証用に保存する。PaddleOCRは本文の自動採用には使わない。
2. 本文・ルビ・柱・ノンブル・図版を分ける。ルビ内の大きい仮名と小書き仮名が割れたときは、大きい仮名に補助票を与える。
3. VLMは不一致部分の原画像を確認する。自動校正は対象文の文字数を変えず、候補外の作文を採用しない。欠落・挿入は人の確認に回す。
4. Jevなどの decision model は候補選択または評価役として、正解を付けたページで有効性を測る。
5. カラー図版は色を維持する。白黒線画の紙色除去は白背景と透過の両方を試し、写真や網点画には一律適用しない。
6. 確認済みの本文から、縦書き・横書きのリフロー可能なEPUBを生成する。
7. OCR前に扉・登場人物一覧・目次・奥付などから確認できる固有名詞を初期辞書に登録する。生成した本文からも人名・地名・用語の候補を追加して表記揺れを検出する。初期辞書はOCR候補の照合・レビューに使い、誤認識を無条件に自動置換しない。
8. 縦書き中のラテン文字は、原画像の並び方で幅を決める。NDLOCRが縦に組まれた全角英字をASCIIへ正規化する場合があるため、OCRテキストの幅情報は原本の組み方の証拠にしない。英字が一字ずつ縦に並ぶ場合は全角、複数字が横にまとまっている場合（縦中横）は半角にする。原画像で組み方を確認してから反映し、判定が曖昧な箇所はレビューに回す。

## 改ページの扱い（2026-10-31調査）

- PDFの各画像ページの境界はOCRに推測させず、PDFページ番号から確実に保持する。OCRの各行・領域にはPDFページ番号を付ける。
- PDFページ100は印刷ページ98で、本文は3列だけ。次のPDFページ101（印刷ページ99）は番号「8」で始まる。構造的な区切りの候補だが、章か節かは目次などとの照合前に決めない。本文が少ないという理由だけで章・場面転換と自動判定しない。
- リフロー可能なEPUBでは、原本の毎ページを強制改ページにせず、原本位置を `epub:type="pagebreak"` / `role="doc-pagebreak"` のマーカーで保持する。原本ページへの移動用に `nav epub:type="page-list"` を作る。ノンブルのOCR文字列は本文から外し、確認できた印刷ページ番号をマーカーのラベルに使う。PDFページ番号との対応表も保持する。
- 章番号・章題などが確認できた箇所は章境界として別のXHTML文書に分け、EPUBのspineで順に並べる。これにより章頭は新しい表示ページから始まる。見開き・端末による差があるため、通常の読書ページ数はリーダー側に任せる。
- 文字数や余白だけで改ページを推定せず、章番号・見出し・装飾・前後ページの内容を候補判定に使い、人がレビューできるようにする。
- 目次がある本では先に目次の章番号・題名・印刷ページ番号を抽出し、ノンブルとの対応表から該当PDFページを絞る。該当ページの見出しと直前ページ末尾を照合し、章頭の位置を確定してからEPUBの目次と章境界を作る。目次にもOCR誤認があるので、文字列の一致だけで確定しない。
- このサンプルの確認済み冒頭PDFページ1〜10には目次が見当たらず、PDFページ101の「8」に題名はない。目次がない本や番号だけの節では、候補を全ページから探して人が確認する。巻末の確認済み379〜388ページは広告と白紙で、目次は見当たらない。
- このサンプルにはPDFページ4に「登場人物」一覧がある。本文OCR前に名前を画像と照合して初期辞書へ登録し、本文中のOCR候補との表記揺れ・誤認識を検出する。辞書レコードには表記、読み（分かる場合）、人物などの種別、出典ページ、確認状態を持たせる。OCR結果と辞書が違うときは辞書だけで強制修正せず、原画像をレビューする。
- PDFページ4をNDLOCR-LiteとPaddleOCRで認識し、`data/cast-seed.tsv` に候補を記録。登場人物15名と別名・本名を掲載。多くは画像で表記を確認したが、「ボ／ポリス」「アロイシャスの末尾」「マコンのン／ハ」「アネット・モスワーノの末尾」は確認待ち。PaddleOCRはキャンディ／キャンデイ、ロジャー／ロジヤーの小書き仮名も誤り、辞書候補作りでは画像確認が必要と分かった。
- 登場人物一覧の点線リーダーが文字差分を膨らませるため、比較CLIとレビューHTMLに任意の `--ignore-leaders` を追加。連続した `……` / `...` を比較対象から外し、名前の中点 `・` と長音 `ー` は残す。PDFページ4は点線を無視すると差分が111から24（NDL 338文字中）に減った。例として `ジュリア・クラレル` の中点をNDLが落とし、キャンディの本名では長音や中点などに差が出る。値はOCR間の不一致量で、正解率ではない。
